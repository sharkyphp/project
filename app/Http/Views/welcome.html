Core Features

⚡

协程引擎

✓

PSR 标准

⬡

依赖注入

Quick Start

三步上手

几分钟内拥有一个可运行的 SharkyPHP 应用。

1

创建项目

使用官方脚手架一键生成标准目录结构。

sharky new my-app
cd my-app
2

安装协程（可选）

安装 Swoole 运行时，启用协程调度能力。

composer require sharkyphp/runtime-swoole
3

启动服务

PHP 内置 HTTP 服务 / Swoole 协程 HTTP 服务。

php serve dev    # PHP 内置 HTTP 服务
php serve swoole # Swoole 协程 HTTP 服务
